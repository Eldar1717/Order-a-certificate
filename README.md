# Система мониторинга готовности справок для колледжа

Веб-приложение для автоматизации процесса заказа и отслеживания статуса справок в учебном заведении.

## 🚀 Возможности

### Для студентов:

* **📋 Заказ справок** - простая форма с указанием ФИО, даты рождения, места требования
* **👀 Просмотр статусов** - мониторинг всех заказанных справок
* **🔍 Поиск справок** - фильтрация по ФИО студента
* **📊 Проверка статуса** - быстрая проверка по номеру справки
* **🆓 Свободный доступ** - не требуется регистрация или пароль

### Для секретарей:

* **👨‍💼 Управление статусами** - изменение статусов справок ("в работе"/"готово")
* **📈 Статистика** - обзор количества справок по статусам
* **🔧 Фильтрация** - поиск по ФИО, месту требования, статусу
* **🔐 Защищенный доступ** - вход по паролю

## 🎨 Дизайн и визуал

Интерфейс собран на небольшой дизайн-системе в одном файле `static/style.css` —
без фреймворков и сборки.

### Что использовано

* **Дизайн-токены** — палитра, радиусы, тени и типографика заданы CSS-переменными
  в `:root`, поэтому тему можно менять в одном месте.
* **Единая сетка** — контейнер 1200px, «мягкие» карточки с тонкой рамкой и
  многослойными тенями, единый шаг отступов.
* **Цветовые статусы** — «в работе» / «готово» / «отклонено» кодируются цветом
  на трёх уровнях: полоса карточки, бейдж и трекер этапов. Это читается даже
  боковым зрением.
* **Трекер прогресса** — на карточке справки видно весь путь: Заказ → В работе → Готово.
* **Иконки** — инлайновый SVG-набор (`templates/_icons.html`), без внешних библиотек
  и лишних запросов.
* **Состояния интерфейса** — загрузка (скелетоны), пустые состояния с подсказкой
  и действием, всплывающие уведомления вместо `alert()`.
* **Доступность** — контраст, фокус-обводки, `aria`-атрибуты, skip-link,
  поддержка `prefers-reduced-motion`.
* **Адаптивность** — мобильная навигация со скроллом, перестройка форм и карточек
  в одну колонку, «липкая» первая колонка таблицы.
* **Печать** — `@media print` убирает навигацию и тени, чтобы карточку справки
  можно было распечатать.

### Как менять оформление

| Задача | Где менять |
| --- | --- |
| Основной цвет, фон, радиусы, тени | переменные в `:root` (`static/style.css`) |
| Цвета статусов | блоки `.status-badge`, `.stat-card--*`, `.certificate-card[data-status]` |
| Новые иконки | словарь `_icons` в `templates/_icons.html` |
| Тексты подсказок и микрокопирайт | соответствующие `templates/*.html` |

## 🔧 Технические особенности
Фреймворк: Flask 2.3.3
База данных: SQLite с SQLAlchemy
Фронтенд: Чистый HTML/CSS/JavaScript
Аутентификация: Сессионная (только для секретаря)
Адаптивность: Responsive design, mobile-first сетка, печатные стили
